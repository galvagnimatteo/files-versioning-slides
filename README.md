# Files API versioning slides

Slides for the Carbonio Files API versioning PoC (Slidev), published with GitHub Pages:
https://galvagnimatteo.github.io/files-versioning-slides/

```bash
pnpm install
pnpm dev     # http://localhost:3030
pnpm build   # static site in dist/
```

The demo branch is `versioning-poc-test-impl` on zextras/carbonio-files-ce. Snippets from
private repositories are shown as pseudocode with a link to the exact line.
